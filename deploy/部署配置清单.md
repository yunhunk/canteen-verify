## 四、执行步骤（按序，全自动化）

```bash
# ① 服务器装 Docker + certbot（已有则跳过）
apt-get update && apt-get install -y docker.io docker-compose-plugin certbot python3-certbot-nginx

# ② 克隆仓库（私密仓库需凭证）或从本地上传源码到服务器
git clone https://github.com/yunhunk/canteen-verify.git /opt/canteen-src

# ③ 放入真实配置
cp <用户提供的.env> /opt/canteen-src/deploy/.env   # 权限 600，勿入库

# ④ 一键部署（构建前端→生成MySQL初始化→起四服务→签证书→冒烟）
cd /opt/canteen-src/deploy && bash deploy.sh
#    前端没改时加速：bash deploy.sh --skip-fe；已签证书：--skip-ssl

# ⑤ 证书续期（Let's Encrypt 90天，配 cron 每月跑一次）
certbot renew --quiet && 重跑 deploy.sh --skip-fe --skip-ssl 同步证书进容器

# ⑥ 改了后端代码时：更新仓库后
docker compose build api && docker compose up -d api
```

## 六、常见坑速查（历次部署实测教训）

| 坑 | 现象 | 解法 |
|---|---|---|
| 实体改了没跑迁移 SQL | 员工登录 500「Unknown column」 | `DB_SYNC=0` 下必须先执行迁移 SQL 再发代码 |
| mock openid 残留 | 切真实微信通道后登录报 1002「已绑定其他微信」 | 清 `openid LIKE 'mock_openid_%'`，重新登录即绑真实微信 |
| git 仓库嵌套 .git | 小程序目录被当子模块、源码传不上去 | 删掉 `miniprogram/.git`（微信开发者工具会建）再提交 |
| 工程路径含中文 | Android 构建报 non-ASCII path | `gradle.properties` 加 `android.overridePathCheck=true` |
| debug/release 混装 | 覆盖安装失败 | 签名不同，先卸载再装 |
| WXML 模板字符串 | 编译报 unexpected '`' | 插值只支持三元/拼接/属性访问，用 `'（' + x + '）'` 代替反引号 |
| 域名没配白名单 | 小程序「网络异常」 | 微信后台 request 合法域名 + 真机杀微信重开 |
| 代理对 github.com 502 | git push 失败但 api.github.com 通 | 退避重试几次即可过 |
| 凭证有效性探测 | 不确定 AppID/Secret 对不对 | 拿假 code 打 jscode2session：40029=凭证对；40013/40125=错 |
