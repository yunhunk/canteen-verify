## 一、非核销时段不出二维码

### 用户看到什么
不在可核销时段时，核销码页**不显示二维码**，改为显示：

```
        🕐
   当前不在可核销时段
   可核销时段：
   · 午餐  11:00 - 13:30
   · 晚餐  17:00 - 19:30
   距离「午餐」开始还有 2 小时 15 分钟

   [ 重新检测 ]   [ 反馈问题 ]
```

- 时段列表按公司实际配置动态生成
- 显示「距下一个时段还有多久」，给用户明确预期；今日时段全部结束后显示「今日时段已结束，请明天再来」
- 公司未配置任何时段规则时 = 不限制，照常出码

### 双保险（防绕过）
前端不出码只是体验层，**后端发码接口同样拦截**。实测（真实时刻 21:58）：

```
GET /api/employee/qrcode
→ HTTP 400  {"code":2005,"message":"当前不在可核销时段，可核销时间：午餐 11:00-13:30、晚餐 17:00-19:30"}
```

即使直接调接口也拿不到码。小程序识别 `code === 2005` 后自动切换到「非时段」呈现，不报错。

## 二、员工反馈功能（仅平台可见）

### 小程序端
**两个入口**：
1. 「我的」页常驻入口
2. 核销码页非时段时的「反馈问题」快捷入口（此时投诉意愿最强）

**页面**：双 tab —— 「我要反馈」/「我的反馈」
- 反馈类型：问题反馈 / 功能建议 / 投诉 / 其他
- 标题 + 内容 + 联系方式（选填）
- 历史列表可看到平台回复，支持下拉刷新与分页

### 平台端（管理后台）
新增「意见反馈」菜单，功能：
- 待处理数量徽标（如「1 条待处理」）
- 筛选：关键词 / 公司 / 类型 / 状态
- 「只看待处理」快捷按钮
- 回复弹窗、详情抽屉、可退回待处理

### 可见范围（严格按需求执行）
| 角色 | 访问 `GET /api/platform/feedbacks` | 结果 |

| 平台超管 | 200，可见全部反馈 + 待处理计数 | ✅ |

公司端后台**没有「反馈」菜单**，路由也只在 `/platform` 子树注册。
